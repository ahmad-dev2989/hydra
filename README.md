### ⚡ Key Metrics

| Metric | Target | Technical Architecture |
| :--- | :---: | :--- |
| **Response Latency** | `< 180 ms` | Streaming token pipeline via Nebius AI & local audio frame buffer |
| **Visual Accuracy** | `99.4%` | Sub-pixel OCR + multi-scale OpenCV template matching |
| **LLM Support** | `7+ Providers` | Multi-tier routing (Nemotron-3.5, Gemini 3.5, Claude, GPT-5, Local) |
| **Credential Storage** | `AES-256 GCM` | Windows DPAPI hardware-bound encryption with zero plaintext leakage |

### 🧠 Execution Modalities

HYDRA routes all incoming requests through an intelligent 5-tier classification engine:

| Modality | Target Subsystem | Functionality |
| :--- | :--- | :--- |
| **`BUILTIN_UI`** | PyQt6 WebEngine HUD | Controls HUD state, holographic overlays, organism particle core, and tray minimization. |
| **`CONVERSATIONAL`** | NVIDIA Nemotron / Gemini | Multi-turn speech reasoning, knowledge Q&A, and low-latency Edge-TTS neural voice. |
| **`HEADLESS_BACKGROUND`** | Direct Worker APIs | Background execution for Spotify playback, WhatsApp messages, Gmail triage, and Classroom tasks. |
| **`FOREGROUND_DESKTOP`** | Verified Executor | Sub-pixel mouse, keyboard, and window automation with OCR confirmation before/after execution. |
| **`ACCOUNT_VAULT`** | Vault Manager + DPAPI | Manages OAuth sessions, credentials, and token rotation with hardware-level encryption. |

### 🚀 Quickstart

#### 📦 Option 1: One-Click Windows Launcher (Recommended)
Double-click the included startup script:
```cmd
run.bat
```
> Automatically sets up Python paths, checks virtual environment status, and initializes the PyQt6 living HUD.

#### 🛠️ Option 2: Manual Developer Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/ahmad-dev2989/hydra.git
   cd hydra
   ```

2. **Create and Activate Virtual Environment:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. **Install Dependencies:**
   ```bash
   pip install PyQt6 PyQt6-WebEngine edge-tts pygame pyautogui opencv-python Pillow pywin32 requests python-dotenv
   ```

4. **Configure Environment:**
   ```bash
   copy .env.example .env
   ```
   Add your API keys to `.env`:
   ```env
   NEBIUS_API_KEY=your_nebius_api_key_here
   GEMINI_API_KEY=your_gemini_api_key_here
   HYDRA_MASTER_NAME=Ahmad
   HYDRA_ASSISTANT_NAME=HYDRA
   ```

5. **Start HYDRA:**
   ```bash
   python main.py
   ```
